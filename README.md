# Navdant Marketing Website

React + Vite + Tailwind CSS landing page for Navdant Dental Clinic.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel detects Vite automatically.
4. Build command: `npm run build`
5. Output directory: `dist`

## Before publishing

- Replace the WhatsApp number in `src/App.jsx`.
- Replace/add your actual contact details.
- Add any additional app screenshots to `public/screenshots/`.
- Replace the temporary text logo with the actual Navdant logo if you have a transparent logo file.
- Add your domain and social links.

## Color palette
